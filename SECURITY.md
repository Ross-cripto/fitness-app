# Security

Momentum keeps everything on the device and makes no network requests of its own, so the main risks are bugs that could corrupt or expose a person's local data, or make the app pick unsafe exercises.

**Reporting a problem.** Please do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting (repository *Security* tab → *Report a vulnerability*), or contact the maintainers through the email on their GitHub profiles. Include what you saw and, if you can, how to reproduce it. We aim to reply within a week.

**Safety bugs count too.** If the app ever plans an exercise that loads a body area the person marked as a problem, or an obviously dangerous load, that is a security-level issue for this project. Report it the same way.

**Supported versions.** Only the latest release.
